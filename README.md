# Jyogi Rooms

じょぎの部室管理システム。
部室の利用状況確認・予約・鍵管理をひとつにまとめた運用アプリです。

## 主な機能

- **部室状況** — 開室/閉室のリアルタイム確認、入退室者の一覧表示
- **部室予約** — カレンダーから予約の作成・編集、Web/Discord両対応
- **鍵管理** — 鍵の所持者確認、譲渡・割り当て
- **利用統計・ランキング** — 訪問日数・滞在時間の集計、部員間ランキング
- **NFCカード対応** — カードをかざすだけで入退室を自動記録
- **Discord Bot連携** — スラッシュコマンドで予約確認・部室状況チェック
- **自動通知** — 入退室・鍵譲渡・予約などのイベントをDiscordに通知

## 技術構成

| コンポーネント | 技術 |
|---|---|
| Webアプリ | Ruby on Rails |
| データベース | PostgreSQL |
| Discord Bot | TypeScript (Cloudflare Workers) |
| 認証 | Discord OAuth2 (jyogi-auth) |

## はじめに

このアプリケーションを開始するには、`devbox` がインストールされている必要があります。

1. **リポジトリをクローンする:**
   ```bash
   git clone <repository_url>
   cd JyogiRooms
   ```

2. **セットアップスクリップの実行:**
   以下のコマンドを実行すると、依存関係のインストール、データベース（PostgreSQL）の構築、および全ての準備が自動的に行われます。
   ```bash
   devbox run setup
   ```

3. **サーバーの起動:**
   セットアップスクリプトによってサーバーは自動的に起動しますが、次回以降は以下のコマンドを使用してください。
   ```bash
   devbox run dev
   ```

## 開発

- **テストの実行:**
  ```bash
  devbox run test
  ```
- **コードの整形（Lint）:**
  ```bash
  devbox run lint
  ```
